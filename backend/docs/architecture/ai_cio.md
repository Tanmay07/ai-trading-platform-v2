# AI Chief Investment Officer Architecture

## Overview
The AI-CIO module is the conversational and strategic intelligence layer of the AI Trading platform. It translates complex quantitative metrics, market events, and portfolio analytics into human-readable insights.

## Core Concepts
- **Multi-Agent Orchestration**: Rather than using a massive prompt, the system routes context to specialized sub-agents. 
- **Context Grounding**: The AI does not rely purely on LLM parametric memory. It is fed a strictly defined `portfolio_context` (holdings, allocations) and `market_context` (recent events from the Event Bus) before generating a response.

## Sub-Agents
1. **Portfolio Analyst**: Evaluates holdings, allocation, and risk concentration.
2. **Market Strategist**: Contextualizes events passing through the `EnterpriseMarketIntelligenceEngine`.
3. *(Future)* **Risk Analyst**: Examines portfolio drawdown limits.
4. *(Future)* **Research Analyst**: Dives deep into individual stock fundamentals.

## Data Flow for Chat
1. User submits a query via `/api/aicio/chat`.
2. The Backend identifies the active portfolio and queries the `MarketDataService` to build the `portfolio_context`.
3. The Backend queries the `MarketEventRecord` table to build the `market_context`.
4. The `AICIOService` (Orchestrator) invokes the sub-agents asynchronously.
5. The Orchestrator synthesizes the sub-agent responses into a cohesive reply and logs the conversation to `conversation_logs` in `ai_cio.db`.

## Reporting
- **Morning Briefing**: Generated by the `ReportGenerator` utilizing the same context builder, formatted specifically as an executive summary for the start of the trading day.
